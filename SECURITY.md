# Security Policy

## Supported Versions

Security updates are actively applied to the following versions of LARS:

| Version | Supported |
| ------- | --------- |
| 1.x     | Yes       |
| < 1.0   | No        |

## Reporting a Vulnerability

We take the security of LARS seriously. If you find a security vulnerability, please do NOT open a public issue. Instead, report it directly to maintainers.

Please send security vulnerability details to **security@lars.dev** (or open a confidential issue if supported by the repository hosting provider).

Be sure to include:
- A description of the vulnerability.
- Detailed steps or a proof-of-concept (PoC) script to reproduce the issue.
- Potential impact of the vulnerability.

We will acknowledge your report within 48 hours and work with you to coordinate a security release to patch the issue before public disclosure.
